# Health Learning Ontology (HLO) — Paper 1 Research Artifacts

## Overview

This repository provides supporting research artifacts for the manuscript:

**LLM-Assisted Ontology Engineering for Context-Aware Medical Residency Education: Design and Evaluation of Health Learning Ontology**

Health Learning Ontology (HLO) is an OWL-based semantic representation integrating biomedical and health-informatics knowledge with educational requirements and contextual dimensions relevant to medical residency learning.

## Repository Contents

### Supplementary S1 — HLO Ontology

`Supplementary_S1_Ontology/`

Contains the refined HLO ontology, including the label-harmonized v1.2 release.

### Supplementary S2 — LLM-Assisted Enrichment

`Supplementary_S2_LLM_Enrichment/`

Contains available prompt instructions and implementation materials for ontology enrichment, including the enrichment notebook and Python prompt files.

### Supplementary S3 — Evaluation

`Supplementary_S3_Evaluation/`

Contains available evaluation scripts, notebooks, scenario-related materials, and recorded results for ontology-level checks and learning-resource ranking assessment.

## Reproducibility

The repository provides available research artifacts to support inspection and verification. Ontology-level evaluations and learning-resource ranking are separate components. The original GPT-4 calls and complete historical resource-ranking execution are not fully documented by the available files.

## Data and Ethical Considerations

Expert validation findings are reported in the manuscript. Individual expert responses are not publicly shared to protect participant confidentiality.
