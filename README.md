# HLO-Paper1
# Supplementary S3 — HLO Evaluation

This directory contains the available evaluation scripts, notebooks, scenario datasets, and recorded results associated with the Health Learning Ontology (HLO) study.

The evaluation materials cover ontology-level parent and reference-code checks and the recorded learning-resource ranking results.

The ontology-level evaluation and the learning-resource ranking evaluation are distinct components. The recorded ranking scores support the statistical comparison reported in Table 5, but the available materials do not establish a complete historical reconstruction of the original resource-ranking runs.

The files are provided to support transparency and verification of the reported results.
